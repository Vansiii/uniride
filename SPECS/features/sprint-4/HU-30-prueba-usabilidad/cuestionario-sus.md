# Cuestionario SUS (System Usability Scale, Brooke 1996)

Marca, para cada afirmación sobre la aplicación que acabas de usar, qué tan de acuerdo estás: **1** = muy en desacuerdo … **5** = muy de acuerdo. Responde todas, con la primera impresión.

| # | Afirmación | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Creo que me gustaría usar esta aplicación con frecuencia. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2 | Encontré la aplicación innecesariamente compleja. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 3 | Pensé que la aplicación era fácil de usar. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4 | Creo que necesitaría el apoyo de una persona técnica para poder usar esta aplicación. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 5 | Encontré que las distintas funciones de la aplicación estaban bien integradas. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 6 | Pensé que había demasiada inconsistencia en la aplicación. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 7 | Imagino que la mayoría de las personas aprendería a usar esta aplicación muy rápidamente. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 8 | Encontré la aplicación muy incómoda de usar. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 9 | Me sentí muy seguro/a usando la aplicación. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 10 | Necesité aprender muchas cosas antes de poder empezar a usar la aplicación. | ☐ | ☐ | ☐ | ☐ | ☐ |

**Puntaje** (lo calcula `sus.mjs`): suma de (respuesta − 1) en las preguntas impares + suma de (5 − respuesta) en las pares, por 2,5. De 0 a 100.

Preguntas abiertas: ¿qué fue lo más difícil? · ¿qué cambiarías?
